# study-reports

Playwright HTML-репорти з CI навчального проєкту [`study/playwright`](https://github.com/andriy-shevchuk/study). Публікуються автоматично workflow `Playwright` того репозиторію: кожен прогін у `runs/<номер>/`, останній у `latest/`. Зберігаються останні 30 прогонів.

Сторінка: https://andriy-shevchuk.github.io/study-reports/
